# ChatGPT Scheduled Tasks

Scheduled tasks let you ask ChatGPT to carry out a task at a specified time or on a recurring schedule. Instead of remembering to repeat the same request, you define the work and when it should happen.

This guide focuses on the practical side: deciding what to automate, writing a useful instruction and checking that the result is still relevant.

## What makes a task worth scheduling?

A good candidate is work that is:

- **Repeatable** — the same broad activity needs to happen more than once.
- **Time-based** — a particular day, time or interval makes sense.
- **Well-defined** — the task has a clear purpose and useful output.
- **Low-risk to automate** — the task can be reviewed before you act on its results.

For example, a weekly opportunity scan can collect relevant events, deadlines and calls for submissions. You can then review the findings and decide what deserves your attention.

## A simple workflow

1. Define the outcome you want.
2. Decide when the task should run.
3. Write instructions that explain what to include and exclude.
4. Create the task in ChatGPT's scheduled-task experience.
5. Review the first result and refine the instructions.
6. Revisit the task when your priorities change.

## Important distinction

Scheduling a task does not make every part of its output automatically correct. Treat results as research to review, especially when they include deadlines, eligibility requirements, prices or other details that can change.
